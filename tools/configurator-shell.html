ACADIA / OPEN CONFERENCE INFRASTRUCTURE

Set up your conference.

Configure one edition, create its Google templates, and download five independent Apps Script projects. This page works offline and sends nothing to a server.

DOWNLOAD → CONFIGURE → DEPLOY

Your installation

  1. Enter this edition’s settings.
  2. Download the template builder. Run it in a new Apps Script project.
  3. Download its configuration JSON from Drive and import it here.
  4. Fill your new Sheets, then export and deploy the modules.
  5. Add the generated embeds to your conference website.

No API keys or passwords belong in this page. Keep your exported settings private.
